Welcome to JobSearch

This short setup collects the information needed to find and rank jobs for you: the roles you want, where and how you want to work, your salary preference, and your resume. We’ll explain each item before asking for it.

Your first test uses built-in sample jobs. It does not require an account with an outside job provider. Near the end, we’ll explain the available providers and let you connect one if you want to run searches against current job listings.

A resume is required to run a search. Keywords and location find possible postings, then your resume is compared with each posting to calculate its match score. Without resume text, the search stops because it cannot rank or apply the match threshold reliably.

You can change everything later from Search setup.

What roles are you looking for?

Enter job titles, specialties, or important skills separated by commas. These are the main search terms used to find possible jobs, so start with a few focused phrases.

How do you want to work?

This controls whether JobSearch looks nationwide for remote work, near your location for on-site work, or both.

What area should local searches use?

Enter a city and state or another region. Job sources use this phrase when looking for local and hybrid openings. If you selected only remote work, you may leave it blank.

What ZIP code should distance checks start from?

The ZIP code gives JobSearch a precise starting point for measuring local-job distance. It is used for filtering only and is not shown to employers. If you selected only remote work, you may leave it blank.

How far are you willing to travel?

Local jobs farther than this radius are filtered out. Remote jobs are unaffected.

Do you have a minimum salary?

When a posting includes salary information, jobs below this amount are filtered out. Jobs that do not publish salary remain eligible. Enter 0 if you do not want a salary filter.

Add your resume

Your resume is required because it is used privately to score every job that passes the basic filters. Without it, JobSearch cannot calculate meaningful match scores and will stop the run. Paste plain text—the content matters more than formatting, and you can replace it later.

Connect live job sources

The sample test works without these accounts. To search current listings, choose one or more providers and supply credentials from your own provider account. Credentials are stored privately and are shown only in masked form after saving.

Adzuna

Searches Adzuna’s job-ad database directly. It often provides broad listings and salary data. Adzuna issues two values: an App ID and an App Key, and applies its own usage limits.

Create an Adzuna API accountHow Adzuna works

SerpAPI

Retrieves structured Google Jobs results. It can add listings that other sources miss. SerpAPI uses one private API key, and each live result-page request generally counts against the account’s monthly search allowance.

Create a SerpAPI accountFind my SerpAPI key

Indeed (experimental)

This built-in scraper does not require an API key, but Indeed frequently blocks automated requests and may return no results. It is disabled by default.

You may leave every live source off and configure one later under Search setup → Scraper credentials. The no-credit sample test will still work.

2. Where, how, and for what pay?

Remote and local searches are separate passes. Local location controls are used only when Search local is enabled. Minimum salary filters postings that publish pay.

3. Priority employers

Check a chosen company during every live search without relaxing your role's normal keyword, location, pay, or resume-match rules. Public SuccessFactors, Workday, UKG, verified Jibe/iCIMS, and qualifying structured-data careers pages are checked directly; a company name or unsupported URL uses SerpAPI and may consume credits.

3. Job sources and search size

Enable Adzuna and SerpAPI from their boxes under Scraper credentials. These controls set how many result pages enabled providers request. More pages can find more jobs but take longer; SerpAPI pages consume provider credits during live runs.

4. Role resume

Required ATS text: JobSearch uses this plain-text version to score jobs and as the source for AI tailoring. Each save creates a new version only when the text changes.
